# Security

If you find a security problem in Katib, please do not open a public issue. Use [private vulnerability reporting](https://github.com/MergenEnBilge/Katib/security/advisories/new) on this repository and include what you did and what you saw.

What Katib protects, what it leaves to you, and what has been reviewed is written up in [docs/security.md](docs/security.md).
